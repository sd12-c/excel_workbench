本目录的数据用于逐项验证软件的全部功能。所有文件都由

建议把每个功能页下方的「运行日志」和输出文件对照本文的**预期结果**检查。

- [ ] 电话列的全角数字/空格/横杠只做文本去空格；不应把 11 位手机号误转成数字。
      （如果要清理空格和横杠，请使用下面的“手机号标准化”列绑定规则。）

- [ ] `公式与格式` 输出为纯数据，不保留公式、填充色、字体等格式。
- [ ] 日期格式改为 `%Y/%m/%d` 后，输出日期应变成 `2026/03/21` 形式。

### 单列绑定规则测试

这一节验证新的**原子清洗配置引擎**。全局复选框仍然对整表生效；下面的绑定规则在全局规则之后，按清单顺序执行。

在“单列绑定规则”区域添加：

| 列名 | 原子规则 | 预期效果 |
| ---- | ---- | ---- |
| `电话` | 手机号标准化 | `138 0013 8001`、`１３８００１３９００１`、`137-0013-9003` 会去掉空格/横杠并转半角；按文本 `@`、居中写入 |
| `工资` | 金额转数字 | `12,800.50`、`￥9,600` 转成数值；Excel 单元格格式为 `#,##0.00`、右对齐 |
| `入职日期` | 日期统一 | 按上方“目标格式”统一；Excel 中写成真正的日期格式、居中 |
| `备注` | 文本格式（@） | 内容不变，只设置文本格式和左对齐 |

验证点：

- [ ] 添加绑定后，清单显示“列名 / 原子规则 / 写入格式”三列。
- [ ] 选中一行或多行，点“删除选中”能删除；未选中时提示先选择。
- [ ] 同一列可以绑定多条规则，例如先“去除文本首尾空格”再“手机号标准化”。
- [ ] 不存在的列（如 `不存在的列`）被绑定时，日志提示缺少绑定列并跳过，不能崩溃。
- [ ] 全局规则先执行：例如全局“去除文本首尾空格”会先清理 ` 张伟 `，再执行列绑定。
- [ ] 只绑定 `入职日期` 日期规则、取消全局“统一日期格式”时，仍然能按列统一日期。
- [ ] 日期失败仍沿用原日志：`三月十五日`、`2026-13-40` 会提示失败并保留原值。
- [ ] 打开输出 Excel，检查 `电话` 为文本、`工资` 为金额格式、`入职日期` 为日期格式且对齐方式正确。
- [ ] 点“保存规则…”保存为 JSON，重新打开程序后点“加载规则…”能恢复全局规则、列绑定和日期选项。
- [ ] 主菜单“保存方案”/“加载方案”也能保存和恢复这些绑定（位于方案 JSON 的 `format.column_bindings`）。

### 额外测试

- 只处理第一张工作表：输出应只有 `脏数据` 一个工作表。
- 取消“识别中文日期”：验证 `2026年3月21日` 是否仍能按当前 pandas 规则解析。
- 去重依据列填 `工号`：重复的 `E005` 只保留一行（与本例全列去重结果相同）。
- 把日期格式填成非法值（如 `%Q`）：应提示格式无效并跳过日期统一。

### 提取指定列

```text
客户名称, 联系人, 电话, 统一社会信用代码
```

- [ ] `客户联系` 应为 **24 行 × 4 列**；`备用客户` 为 10 行，并提示缺少“统一社会信用代码”。
- [ ] 统一社会信用代码 `001234567890123X` 等前导零应保留。
- [ ] 只提取第一张表时，不出现“备用客户”的缺列警告。

### 单条替换

```text
查找：迅达电子
替换为：迅达科技
列：客户名称

```

- [ ] `迅达电子（重庆）` → `迅达科技（重庆）`，`迅达电子·成都分公司` → `迅达科技·成都分公司`。
- [ ] 其他客户名称不变。
- [ ] 取消所有工作表后，只修改第一张表。

### 导入对照表替换

选择 `替换对照表.xlsx`，勾选“使用对照表”。

对照表有 8 条有效规则（空查找内容自动跳过）：

```text
迅达电子 → 迅达科技
恒信贸易 → 恒信集团
北京 → 北京市
A-001 → A001
^A-(\d+)$ → A\1
(\d{4})-(\d{2})-(\d{2}) → \3/\2/\1
excel → Excel
旧名称 → 新名称
```

- [ ] 不勾选“使用正则表达式”：只按普通文本替换；`^A-...`、`(\d{4})...` 不会按正则生效。
- [ ] 勾选“使用正则表达式”：`A-001` 等编号、`2026-03-01` 等日期会按分组规则转换。
- [ ] 不区分大小写时，`excel / Excel / EXCEL` 都会被改成 `Excel`；
      区分大小写时只改小写 `excel`。
- [ ] 前后导零编号（如 `001`、`000000000000002`）在输出中保留。
- [ ] 输入非法正则（如 `[`）时，应提示“正则表达式无效”，不能出现 Traceback。

> 非正则模式约修改 53 个单元格，正则模式约修改 82 个单元格；具体数量会随“区分大小写”选项变化。
